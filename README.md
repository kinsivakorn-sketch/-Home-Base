# Home Base

A personal home base for news, today, schedule, goals, diary, routine and finance.
It is a static web app (installable on a phone). Everything you type is stored on your own phone, not in this repository.

- `index.html` is the whole app.
- `news.json` is rebuilt every morning by `.github/workflows/news.yml` (headlines and links from Google News).
- `watchlist.json` lists the tickers whose headlines are collected.
